# song_notes/

Drop your own notes about Archer's songs here as `.md` or `.txt` files: one file per song works well, but one big file is fine too (the indexer chunks by paragraph either way).

## Format

Plain Markdown or plain text. A simple per-song structure works well:

```markdown
# Song Title

## Meaning
What the song is about, in your own words.

## Backstory
When/why it was written, what was going on.

## Creation notes
Instrumentation, recording details, any Cree phrase/title and what it
means to you and why you used it.
```
